# README — Meet 17: Challenge Project

## Tujuan Sesi
Meet 17 adalah sesi **guided challenge project**. Siswa menggunakan kembali materi Python dan Tkinter yang sudah dipelajari pada Meet 1–16 untuk membuat aplikasi sederhana dengan ide mereka sendiri.

## Yang Perlu Dilakukan Teacher

1. **Mulai dengan review singkat.**  
   Ajak siswa mengingat kembali kemampuan yang sudah dipelajari: input, variable, operator, conditional, loop, function, list/dictionary, Tkinter, Frame, layout, Entry, Button, command, application logic, dan file handling.

2. **Jangan langsung meminta siswa coding.**  
   Gunakan bagian brainstorming di slide untuk membantu siswa menentukan:
   - masalah atau kebutuhan yang ingin diselesaikan,
   - siapa pengguna aplikasinya,
   - input yang dibutuhkan,
   - output yang ditampilkan,
   - fitur utama,
   - data apa yang perlu disimpan.

3. **Bantu siswa mempersempit scope.**  
   Project tidak perlu besar. Targetnya adalah aplikasi sederhana yang **selesai dan berfungsi**, bukan aplikasi dengan terlalu banyak fitur.

4. **Pastikan project memiliki komponen minimum.**
   - Tkinter GUI
   - Frame/layout yang rapi
   - Input pengguna
   - Button + command
   - Function / application logic
   - Output yang terlihat di aplikasi
   - Penyimpanan data ke file `.txt`

5. **Biarkan siswa mencoba terlebih dahulu.**  
   Teacher berperan sebagai fasilitator. Jangan langsung memberikan full code. Gunakan clue/hint pada slide ketika siswa stuck.

6. **Lakukan checkpoint selama proses build.**
   - UI sudah muncul
   - Input bekerja
   - Button menjalankan function
   - Logic menghasilkan output yang benar
   - Data berhasil disimpan/dibaca
   - Tampilan sudah cukup rapi dan mudah digunakan

7. **Akhiri dengan testing dan mini showcase.**  
   Minta siswa mencoba aplikasi teman, mencatat bug atau hal yang bisa diperbaiki, lalu beberapa siswa dapat mendemonstrasikan project mereka.

## Catatan
Siswa **tidak wajib menggunakan semua materi Meet 1–16**. Yang terpenting adalah mereka mampu memilih konsep yang sesuai untuk project mereka dan menjelaskan bagaimana programnya bekerja.
